## 项目概况

**lazyssh** — Terminal-based interactive SSH manager inspired by lazydocker and k9s。通过键盘驱动的 TUI 直接管理 `~/.ssh/config` 中定义的服务器，支持快速 SSH 连接、服务器增删改查、端口转发、标签管理、批量操作等。

当前版本 v0.1.0，处于早期开发阶段，用户群体为习惯终端的 DevOps/后端开发者，核心理念：零配置安全、非破坏性写入、纯键盘操作。

## PRD 编号规则

1. 查看 `docs/product/` 目录下已有 PRD 文件
2. 取最大序号 +1，补零至 4 位
3. 示例：已有 PRD-0003-xxx.md → 新文件为 PRD-0004-yyy.md

## PRD 格式

用户故事(As a/I want/So that) + GWT 验收标准 + 优先级 P0/P1/P2 + 显式边界 + Assumptions

由于本项目是 TUI 应用，PRD 须包含：

| UI 状态 | 说明 |
|---------|------|
| 正常态 | 数据正常展示 |
| 空态 | 无服务器时的列表占位 |
| 错误态 | 文件损坏/权限问题的提示与恢复 |
| 加载态 | 启动 loader / 刷新时的等待状态 |
| 边界态 | 极端数据（超长别名、海量服务器等） |

## 工作流

新功能规划：
1. 读 `docs/MEMORY_BANK.md`（当前冲刺、雷区）
2. Problem Framing → 明确用户问题
3. PRD → 用户故事 + GWT 验收 + 优先级
4. 拆用户故事 → 排优先级
5. 更新 MEMORY_BANK

需求评审：
- 完整性检查：是否覆盖所有 UI 状态
- 反模式识别：与其"新增配置项"不如思考是否能自动推断

## 项目约束

- **TUI 应用**：所有交互基于键盘，不超过 2 次按键可达核心功能
- **零配置安全**：不引入新的凭证存储，不修改私钥文件
- **非破坏性操作**：编辑 `~/.ssh/config` 前自动备份，原子写入
- **跨平台**：Linux、macOS、Windows，兼容 OpenSSH 客户端
- **现有功能**：服务器 CRUD、SSH 连接、模糊搜索、标签、固定、端口转发、Ping
